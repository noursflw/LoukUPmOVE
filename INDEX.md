## ✨ Key Concepts Across All Docs

**Concept 1: The Bug**
- TimeSpan comparison loses date context
- 23:30 > 00:15 numerically (wrong)
- 23:30 on day 1 < 00:15 on day 2 (correct)

**Concept 2: The Fix**
- Use full DateTime objects
- Include appointment date
- Auto-adjust for cross-day scenarios

**Concept 3: The Principle**
- Never use TimeSpan alone for time logic
- Always include date when date matters
- Use complete DateTime for comparisons

**Concept 4: The Impact**
- Fixes midnight reminders
- Fixes late evening reminders
- Makes reminders independent of provider hours
